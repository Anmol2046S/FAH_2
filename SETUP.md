# FAH 2 - Setup Guide\n\n## Quick Start (2 minutes)\n\n### Prerequisites\n- Modern web browser (Chrome, Firefox, Safari, Edge)\n- Text editor (VS Code, Sublime, etc.)\n- Basic knowledge of HTML/CSS/JavaScript\n\n### Installation\n\n```bash\n# Clone repository\ngit clone https://github.com/Anmol2046S/FAH_2.git\ncd FAH_2\n\n# Open in browser\n# Option 1: Direct open\nopen index.html\n\n# Option 2: Using Python\npython -m http.server 8000\n# Visit http://localhost:8000\n\n# Option 3: Using Node.js\nnpx http-server\n# Visit http://localhost:8080\n```\n\n## Detailed Setup\n\n### Step 1: Clone Repository\n\n```bash\ngit clone https://github.com/Anmol2046S/FAH_2.git\ncd FAH_2\n```\n\n### Step 2: Choose Your Server Method\n\n#### Method A: Python (Recommended)\n```bash\n# Python 3\npython -m http.server 8000\n\n# Python 2\npython -m SimpleHTTPServer 8000\n\n# Visit http://localhost:8000\n```\n\n#### Method B: Node.js\n```bash\n# Install http-server globally\nnpm install -g http-server\n\n# Run from project directory\nhttp-server\n\n# Visit http://localhost:8080\n```\n\n#### Method C: Direct Browser\n```bash\n# Simply open the file\nopen index.html\n# Or drag index.html to browser\n```\n\n### Step 3: Verify Installation\n\n- Open browser to http://localhost:8000 (or 8080)\n- You should see the FAH 2 interface\n- Try analyzing a food item\n- Check browser console (F12) for errors\n\n## Project Structure\n\n```\nFAH_2/\n├── index.html      # Main HTML page\n├── app.js          # Application logic\n├── style.css       # Styling\n├── LICENSE         # MIT License\n├── README.md       # Project documentation\n├── SETUP.md        # This file\n└── .gitignore      # Git ignore patterns\n```\n\n## File Descriptions\n\n### index.html\n- Main HTML structure\n- Form inputs\n- Results display\n- Scripts and styles loading\n\n### app.js\n- API calls\n- Form handling\n- Data processing\n- DOM manipulation\n- Event listeners\n\n### style.css\n- Layout and grid\n- Colors and typography\n- Responsive design\n- Animations\n- Dark mode support\n\n## Configuration\n\n### API Endpoint\n\nEdit `app.js` to set your API:\n\n```javascript\nconst API_BASE_URL = 'https://your-api-endpoint.com';\nconst API_KEY = 'your-api-key';\n```\n\n### Custom Styling\n\nEdit `style.css` to customize:\n\n```css\n/* Primary color */\n:root {\n  --primary-color: #007bff;\n  --secondary-color: #6c757d;\n  --success-color: #28a745;\n}\n```\n\n## Development Mode\n\n### Using VS Code\n\n1. Install \"Live Server\" extension\n2. Right-click `index.html`\n3. Select \"Open with Live Server\"\n4. Changes auto-reload\n\n### Using Terminal\n\n```bash\n# Watch for file changes (requires watchify or similar)\nwatchify app.js -o app.bundle.js\n```\n\n## Browser Console\n\nOpen browser DevTools (F12) to:\n- View errors\n- Debug API calls\n- Check network requests\n- Inspect elements\n\n## Troubleshooting\n\n### \"Port Already in Use\"\n```bash\n# Use different port\npython -m http.server 8001\n\n# Or kill process on port 8000\n# Linux/Mac: lsof -ti:8000 | xargs kill -9\n# Windows: netstat -ano | findstr :8000\n```\n\n### \"CORS Error\"\n- Check API endpoint\n- Verify CORS headers\n- Use proxy if needed\n- Check browser console\n\n### \"Files Not Found\"\n- Check file paths in HTML\n- Verify file names match\n- Check working directory\n- Use relative paths\n\n### \"CSS Not Loading\"\n- Hard refresh (Ctrl+Shift+R)\n- Clear browser cache\n- Check CSS file path\n- Verify style.css exists\n\n### \"JavaScript Errors\"\n- Check console (F12)\n- Verify app.js exists\n- Check for syntax errors\n- Review API configuration\n\n## Testing\n\n### Test Food Items\n```\nApple, Banana, Chicken, Rice, Salmon, Broccoli, Eggs\n```\n\n### Expected Results\n- Nutritional values displayed\n- Health score calculated\n- Recommendations shown\n- No console errors\n\n## Performance Tips\n\n- Minimize images\n- Cache API responses\n- Use debouncing for search\n- Lazy load content\n- Minimize CSS/JS files\n\n## Security Notes\n\n- Never commit API keys\n- Use environment variables\n- Validate all inputs\n- Sanitize outputs\n- Use HTTPS in production\n- Set CORS appropriately\n\n## Deployment\n\n### GitHub Pages\n\n1.
